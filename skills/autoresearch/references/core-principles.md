# Core Principles from Autoresearch

These seven universal principles apply to autonomous work across domains:

**1. Constraint as Enabler**
Intentional boundaries—like a 630-line codebase or single success metric—paradoxically empower autonomous systems by enabling full context comprehension and rapid feedback loops.

**2. Strategy-Tactic Separation**
Humans establish direction ("improve performance"), while agents handle execution ("optimize algorithm"). This division prevents wasting creative human capacity on implementation details.

**3. Mechanical Metrics**
"If you can't verify with a command, you can't iterate autonomously." Success requires testable, quantifiable measures—not subjective assessments like "looks better."

**4. Fast Verification**
When verification time exceeds work time, it discourages iteration. Prioritize rapid checks (unit tests, linting) over slower validation methods during autonomous loops.

**5. Iteration Cost Economics**
Cheaper iterations enable bolder experimentation. A 5-minute cycle enables 100 experiments nightly; a 10-second test cycle permits 360 per hour.

**6. Git as Documentation**
Commits function as memory—tracking causality, enabling stacking improvements, revealing patterns, and allowing human inspection of agent decision sequences.

**7. Transparent Limitations**
Honestly communicate what the system cannot accomplish rather than speculating beyond capability boundaries.

The overarching insight: autonomy thrives through constraint, not despite it—and humans gain value by focusing on strategy rather than tactical execution.
